# Assessment Criteria

## 1. Outcome Approach — 50 Points

### HD — 50 to >39.0 pts

**Outstanding across the course.**

* The approach is an **excellent and extremely thorough investigation** of the chosen ML problem.
* It explores **multiple algorithms and techniques** for solving the problem.
* It goes beyond using the tools provided in class.
* There are **no gaps** in what the investigation has considered.
* The approach makes careful consideration of the **unique aspects of the chosen ML problem**.
* The choices made throughout the investigation are **highly justified and excellently explained**.
* The reader is left with **no unanswered questions** regarding the decisions made.
* The approach demonstrates excellent design across:

  * Training data selection
  * Data preprocessing
  * Model training
  * Hyperparameter tuning
  * Model evaluation
* Demonstrates understanding not only of **building the ML model**, but also of **integrating the ML model into a real-world application**.

---

## 2. Ultimate Judgement and Evaluation — 30 Points

### HD — 30 to >24.0 pts

**Outstanding across the course.**

* An **Ultimate Judgement** is established and exceptionally justified.
* The evaluation of the Ultimate Judgement is **exceptional and clearly demonstrated**.
* The evaluation clearly **demonstrates or proves the viability of the trained model in real-world practice**.
* The evaluation is **independent**.

---

## 3. Report Presentation — 20 Points

### HD — 20 to >17.0 pts

**Outstanding across the course.**

* The report is **easy to read and flows well**.
* The report is **well structured**, leading the reader to fully understand the rationale behind the final approach.
* Approaches are **excellently described**.
* Tables, figures, and other visualisations are **appropriately tailored** to the descriptions and justifications provided in the report text.
* Visualisations should directly support the **analysis, explanations, and decisions** presented in the report.

---

## HD Checklist

To achieve an HD standard, the project should demonstrate:

### Machine Learning Investigation

* [ ] Investigate multiple ML algorithms.
* [ ] Go beyond techniques taught directly in class.
* [ ] Clearly explain why each algorithm/technique was considered.
* [ ] Address the unique characteristics of the chosen ML problem.
* [ ] Ensure there are no significant gaps in the investigation.

### Data & Preprocessing

* [ ] Justify training/validation/test data selection.
* [ ] Thoroughly investigate data quality.
* [ ] Justify preprocessing decisions.
* [ ] Handle missing values appropriately.
* [ ] Investigate outliers and unusual observations.
* [ ] Consider feature selection/engineering.
* [ ] Check for multicollinearity and data leakage where relevant.

### Model Development

* [ ] Train multiple candidate models.
* [ ] Justify algorithm selection.
* [ ] Perform appropriate hyperparameter tuning.
* [ ] Use appropriate validation methodology.
* [ ] Keep comparisons fair by using consistent data splits/evaluation procedures.
* [ ] Explain why the final model was selected.

### Evaluation & Ultimate Judgement

* [ ] Define a clear Ultimate Judgement.
* [ ] Support the judgement with quantitative evidence.
* [ ] Use appropriate evaluation metrics.
* [ ] Demonstrate the model's viability in a real-world context.
* [ ] Evaluate limitations and potential failure cases.
* [ ] Provide an independent evaluation rather than relying only on training results.

### Real-World Application

* [ ] Explain how the ML model could be integrated into a real-world application.
* [ ] Discuss practical deployment considerations.
* [ ] Consider performance, scalability, reliability, and usability where relevant.
* [ ] Explain how predictions would be used by the end user or application.

### Report Presentation

* [ ] Organise the report with a clear logical flow.
* [ ] Explain the rationale behind major decisions.
* [ ] Use tables and figures to support the discussion.
* [ ] Ensure every important visualisation is explained in the text.
* [ ] Make visualisations directly relevant to the analysis.
* [ ] Ensure the report is easy to read and professionally presented.
